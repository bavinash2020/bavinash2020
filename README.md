# OYD (Own Your Driver) - MCA Project

This is a React + TypeScript + Vite project for the OYD (Own Your Driver) MCA project.

## Prerequisites

Before you begin, ensure you have the following installed on your local machine:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js) or [Yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

## Installation & Setup

Follow these steps to get the project up and running locally:

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/bavinash2020/bavinash2020.git
   cd bavinash2020
   ```

2. **Install dependencies**:
   Run the following command in the root directory of the project to install all required packages from `package.json`:
   ```bash
   npm install
   ```
   *(If you are using yarn, run `yarn install`. For pnpm, run `pnpm install`)*

3. **Start the development server**:
   Once the dependencies are installed, you can run the project locally:
   ```bash
   npm run dev
   ```
   This will start the Vite development server. Open your browser and navigate to the URL shown in your terminal (usually `http://localhost:5173/`).

## Available Scripts

In the project directory, you can also run:

- `npm run build`: Compiles TypeScript and builds the app for production to the `dist` folder.
- `npm run lint`: Runs ESLint to check for code quality and errors.
- `npm run preview`: Locally previews the production build generated by `npm run build`.
